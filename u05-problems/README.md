# Unit 5: Problems, Problem Solving and AI Structures

Programs for Unit 5 of the CSC 309 lecture note.

| Program | What it does |
|---|---|
| `explosion.py` | how fast a search tree grows (combinatorial explosion) |

Run a program from this folder, for example `python explosion.py`.
Run the whole unit from the top folder with `python tests/run_all.py u05`.
