# Unit 13: Expert Systems

Programs for Unit 13 of the CSC 309 lecture note.

| Program | What it does |
|---|---|
| `genfault.py` | a small rule-based expert system that advises on why a petrol generator will not start or runs badly |
| `malaria_advisor.py` | a tiny backward-chaining expert system that explains itself |

Run a program from this folder, for example `python genfault.py`.
Run the whole unit from the top folder with `python tests/run_all.py u13`.
