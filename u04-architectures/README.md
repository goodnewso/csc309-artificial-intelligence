# Unit 4: Agent Architectures, Multi-Agent Systems and Robots

Programs for Unit 4 of the CSC 309 lecture note.

| Program | What it does |
|---|---|
| `ants.py` | a colony of simple reflex agents foraging for food |
| `boids.py` | flocking from three local rules (after Reynolds, 1987) |
| `boids_animation.py` | an AI animation exercise: animate a flock of boids |
| `example_traffic_light.py` | a simple reflex controller versus a model-based one at a junction (an example in the student note) |
| `lawn.py` | a lawn-trimming robot with a bump sensor, two ways |
| `messages.py` | communicating agents searching a network |

Run a program from this folder, for example `python ants.py`.
Run the whole unit from the top folder with `python tests/run_all.py u04`.
