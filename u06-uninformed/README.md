# Unit 6: Uninformed Search

Programs for Unit 6 of the CSC 309 lecture note.

| Program | What it does |
|---|---|
| `example_bfs_dfs.py` | the order in which BFS and DFS expand a small tree (an example in the student note) |
| `frontier_trace.py` | watch the frontier of breadth-first and depth-first search |
| `roadmap.py` | route finding on a simplified road map of Rivers State |
| `search.py` | problem-solving agents' search algorithms (Units 6 and 7) |
| `solve_mc.py` | four uninformed searches on missionaries and cannibals |

Run a program from this folder, for example `python frontier_trace.py`.
Run the whole unit from the top folder with `python tests/run_all.py u06`.
