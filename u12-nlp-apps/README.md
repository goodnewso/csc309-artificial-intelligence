# Unit 12: Applications of Natural Language Processing

Programs for Unit 12 of the CSC 309 lecture note.

| Program | What it does |
|---|---|
| `chatbot.py` | an intent-based chatbot for student services |
| `qa.py` | a small question-answering system over course facts |
| `sentiment.py` | lexicon-based sentiment analysis with negation and intensifiers |
| `spam.py` | a naive Bayes filter for unwanted text messages |
| `speech_dtw.py` | speech recognition by template matching with dynamic time warping (DTW), the method of early isolated-word recognisers |
| `spell.py` | a spelling corrector built on edit distance and word frequency |
| `translate.py` | why machine translation needs more than a dictionary |

Run a program from this folder, for example `python chatbot.py`.
Run the whole unit from the top folder with `python tests/run_all.py u12`.
