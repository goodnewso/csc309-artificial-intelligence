# Unit 7: Heuristic Search, Local Search and Games

Programs for Unit 7 of the CSC 309 lecture note.

| Program | What it does |
|---|---|
| `example_astar_drone.py` | A* for a delivery drone over a small network (an example in the student note) |
| `genetic_queens.py` | a genetic algorithm for the 8-queens problem |
| `puzzle8.py` | how much a good heuristic saves on the 8-puzzle |
| `queens.py` | local search for the 8-queens problem |
| `route_astar.py` | uninformed versus heuristic search on the road map |
| `tictactoe.py` | minimax and alpha-beta search for noughts and crosses |

Run a program from this folder, for example `python genetic_queens.py`.
Run the whole unit from the top folder with `python tests/run_all.py u07`.
