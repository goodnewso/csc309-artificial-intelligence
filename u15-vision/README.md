# Unit 15: Introduction to Computer Image Recognition

Programs for Unit 15 of the CSC 309 lecture note.

| Program | What it does |
|---|---|
| `digits.py` | recognising handwritten digits with k-nearest neighbours |
| `edges.py` | finding edges in an image by convolution |
| `example_edge_patch.py` | a 3 x 3 kernel finding a vertical edge (an example in the student note) |
| `faces.py` | a simulation of facial recognition by feature vectors |

Run a program from this folder, for example `python digits.py`.
Run the whole unit from the top folder with `python tests/run_all.py u15`.
