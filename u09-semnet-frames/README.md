# Unit 9: Semantic Networks and Frames

Programs for Unit 9 of the CSC 309 lecture note.

| Program | What it does |
|---|---|
| `frames.py` | frames with slots, facets, defaults and demons |
| `semnet.py` | a semantic network with inheritance and exceptions |

Run a program from this folder, for example `python frames.py`.
Run the whole unit from the top folder with `python tests/run_all.py u09`.
