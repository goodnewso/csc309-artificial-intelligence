# Unit 3: Intelligent Agents and Their Environments

Programs for Unit 3 of the CSC 309 lecture note.

| Program | What it does |
|---|---|
| `example_fan_agent.py` | a simple reflex agent that controls a room fan (an example in the student note) |
| `vacuum.py` | three cleaning agents in the same environment |

Run a program from this folder, for example `python vacuum.py`.
Run the whole unit from the top folder with `python tests/run_all.py u03`.
