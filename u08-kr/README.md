# Unit 8: Knowledge Representation and Reasoning

Programs for Unit 8 of the CSC 309 lecture note.

| Program | What it does |
|---|---|
| `bayes.py` | probabilistic reasoning about a suspicious text message |
| `bayes_network.py` | probabilistic reasoning with a small Bayesian network |
| `defaults.py` | non-monotonic reasoning with default rules |
| `example_rain_bayes.py` | updating a belief with Bayes' rule (an example in the student note) |

Run a program from this folder, for example `python bayes.py`.
Run the whole unit from the top folder with `python tests/run_all.py u08`.
