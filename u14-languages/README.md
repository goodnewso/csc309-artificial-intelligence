# Unit 14: Programming Languages for AI

Programs for Unit 14 of the CSC 309 lecture note.

| Program | What it does |
|---|---|
| `courses.lisp` | the same knowledge base in Common Lisp |
| `courses.pl` | the course-prerequisite knowledge base in Prolog |
| `courses.py` | the same prerequisite knowledge in Python |
| `example_family.lisp` | the family example as Lisp lists (an example in the student note) |
| `example_family.pl` | facts, a rule and a query (an example in the student note) |
| `example_family.py` | the Prolog family example written in Python (an example in the student note) |

Run a program from this folder, for example `python courses.lisp`.
Run the whole unit from the top folder with `python tests/run_all.py u14`.
